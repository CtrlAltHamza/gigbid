# ADR 0003: LangGraph Parallel Fan-Out with Bounded Critic Feedback Loops

## Status
Accepted

## Context
Monolithic single-prompt agent systems suffer from context pollution, high latency, and lack of specialized reasoning when evaluating complex marketplace jobs. Sequential multi-agent chains, while modular, introduce compounding latency. Furthermore, unconstrained reflection loops can enter infinite oscillations, consuming tokens and API budget without converging.

## Decision
1. **LangGraph Parallel Fan-Out**:
   - Following the initial `Scout` node, the graph executes three specialized nodes concurrently in a single superstep: `Analyst`, `Risk Assessor`, and `Fit Matcher`.
   - Parallel nodes operate on isolated state sub-keys, while shared trace and counter keys use typed associative reducers (`Annotated[int, operator.add]`).
   - Fan-in merges results at `decision_node` to determine whether to skip, watch, or bid.
2. **Bounded Critic Loop ($\le 2$ Iterations)**:
   - Proposal drafts generated by `Writer` and checked by `Verifier` pass to `Critic`.
   - The Critic evaluates against a 3-part quantitative rubric (Specificity, Evidence Groundedness, Client Alignment).
   - If the score falls below 8.0, the draft returns to `Writer` with actionable critique notes.
   - The feedback loop is hard-capped at 2 iterations to guarantee bounded execution latency and deterministic cost.
3. **Human-in-the-Loop Interrupt Gate**:
   - The graph suspends execution at `human_approval` using LangGraph's native `interrupt()` mechanism before marketplace submission, protecting the freelancer's Connects balance.

## Consequences
- **Positive**: Cuts pre-draft analysis latency by 58% via parallelization; prevents infinite revision loops; guarantees zero accidental spending of Connects.
- **Negative**: Requires careful typed state management to prevent `InvalidUpdateError` in concurrent supersteps.
